🪟 Windows

O'zida Java bilan keladi — alohida hech narsa o'rnatish shart emas.

  1. Backend dasturini yuklab, .exe faylini ishga tushiring (fonda ishlab turadi)
  2. Premiere plaginini yuklab, ZIP ichidagi install.batni ishga tushiring
  3. Premiere Pro'ni (qayta) oching — Window > Extensions > Uzbek AI Captions
Backend (.exe) yuklab olish
Premiere plagini yuklab olish

Birinchi ishga tushirishda Windows "Noma'lum dasturchi" ogohlantirishi berishi mumkin — "Ko'proq ma'lumot" → "Baribir ishga tushirish"ni bosing.

🍎 macOS

O'zida Java bilan keladi — alohida hech narsa o'rnatish shart emas.

  1. Backend dasturini (.dmg) yuklab, oching va Applications'ga sudrab tashlang, ishga tushiring
  2. Premiere plaginini yuklab, Terminal orqali bash install.command buyrug'ini ishga tushiring
  3. Premiere Pro'ni (qayta) oching — Window > Extensions > Uzbek AI Captions
Backend (.dmg) yuklab olish
Premiere plagini yuklab olish

Birinchi ochishda macOS Gatekeeper ogohlantirishi berishi mumkin — Finder'da faylga o'ng tugma bilan bosib "Open"ni tanlang.
